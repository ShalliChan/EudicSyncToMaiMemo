# 故障排查

- 配置错误：检查 Variables 中的 MAIMEMO_NOTEPAD_ID。不是 Secret，不是网页数字 ID。空格、截断或目标不一致会停止运行。
- OAuth 失败：按[授权说明](maimemo-oauth.md)处理，不向 Issue 粘贴凭证，不导出 GitHub Secrets。
- 欧路失败：核对自己的 EUDIC_AUTHORIZATION 和 EUDIC_BOOK_ID。
- ready=0：检查章节模式、非法行和重复标题，不以清空词本或放宽规则绕过保护。
- extra>0：合法历史标题允许保留；欧路取消收藏不删除墨墨内容。
- 写后 GET 不一致：停止排查，不自动重试、覆盖、回滚或重建词本。

prepared_union_equal=1 表示计划结果等于“原有标题 ∪ 当前有效源标题”，通过原文保留及再次零新增检查。current_set_equal=1 在增量策略下表示源标题已全部包含在目标，不要求 extra=0。不要套用历史词条数量。

GitHub 会把与 Secret 重合的片段遮罩为 ***，包括部分数字；不要关闭遮罩或打印凭证，结合通过的保护指标判断。

GitHub 定时可能延迟或被平台停用；检查 Actions 启用状态与运行记录，不保证准点。

只有独立有效标题参与同步。笔记、Markdown 或歧义记录会跳过，只记录原因和数量。App 自动展示的词形、关联表达不能直接当作同步正文新增。

部分墨墨短语仍需在 App 内“自编此单词”提交。创建释义接口是否完全等价未获确认，不自动生成释义或复制整篇学习笔记。

本地 .NET 和 Windows 服务使用本机配置的凭证，与 GitHub OAuth 包装流程分开。Legacy 网页模式是保留的旧功能，不是推荐的无人值守授权方案。
